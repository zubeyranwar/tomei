## Install by URL

Works anywhere, no setup. Copy the command from any item page.

```bash
npx shadcn@latest add https://tomei.zubeyr.dev/ui/r/button.json
```

## Install by namespace

Add the registry to your `components.json`, then run `npx shadcn@latest add @tomei/<name>`.

```json
{
  "registries": {
    "@tomei": "https://tomei.zubeyr.dev/ui/r/{name}.json"
  }
}
```
