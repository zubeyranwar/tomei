## Install with @tomei

<Steps>
  <Step title="Register the namespace">
    Run this once per project. It adds `@tomei` to the `registries` in your `components.json`.

```bash
npx shadcn@latest registry add @tomei=https://tomei.zubeyr.dev/ui/r/{name}.json
```

  </Step>
  <Step title="Add items">

```bash
npx shadcn@latest add @tomei/button @tomei/card
```

  </Step>
</Steps>

<Callout type="tip" title="Listed in the shadcn directory">
  Once `@tomei` is in the [shadcn registry directory](https://ui.shadcn.com/docs/directory), you can
  skip step 1: the CLI finds the namespace and registers it for you on the first `add`.
</Callout>

Prefer editing the file yourself? This is what step 1 writes:

```json
{
  "registries": {
    "@tomei": "https://tomei.zubeyr.dev/ui/r/{name}.json"
  }
}
```

## Browse from the terminal

Search the registry and read an item before you add it.

```bash
npx shadcn@latest search @tomei -q date
npx shadcn@latest view @tomei/date-picker
```

## Install by URL

Works anywhere, with no setup. Copy the command from any item page.

```bash
npx shadcn@latest add https://tomei.zubeyr.dev/ui/r/button.json
```

## What gets installed

- The item's files land in `components/<scenario>/`, or `components/<scenario>/<name>/` when an
  item has several files.
- npm dependencies are installed with your package manager.
- Other Tomei items it builds on come along automatically.
- Extra CSS variables, like `--shadow-card`, are added to your global CSS.
